# Log Entry Schema

Each character has one log file. Each entry in that file is headed by
its date, with these fields underneath:

- Date: orders the entries
- Scene text: keeps the old wording to differentiate from  later
- Answer: What the user tracks for change
- Why (one or more quoted lines): The exact lines that drove the answer,
  not a conclusion about them. When the shift is about overall tone, vibe,
  or characterization rather than one clear moment, it still has to show up
  as several quoted lines pulled from different spots in the scene, never
  as a summary sentence like "he seems colder now." If you can't point to
  the actual words showing it, it isn't evidence yet.
- Agreement count: Tells you if that day's answer was solid or a
  toss-up, so a changed answer can be told apart from a shaky one
