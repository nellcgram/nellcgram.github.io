Run 2 — [2026-09-10] (graded against run-02-output.md)

Update - [2026-09-12]

  • Scored against SKILL.md as it stood before the 2026-09-12 edits — including before the no-live-user genre fallback was added, which is exactly the gap this run's own genre note describes. Differences from the current SKILL.md are expected, not new defects.

Grading limitations, both carried over from Run 1 and unresolved here: this run was graded in the same session that produced the output, so the grader had the skill loaded (see Future Improvements in the case study). Verification was done via web search against publisher pages, Goodreads, and reader reviews, not by reading the books — the same ceiling Run 1 hit on criteria 9 and 10.

Vetting note: 15 titles were shortlisted, checked against already-read.md, and verified before this list was finalized. 8 candidates that came up during that process were rejected and never reached a draft output: two for violating "no main character who rapes, molests, stalks, tortures, or kidnaps another character" (From Blood and Ash — the male lead kidnaps and cages the female lead, both main characters; Assistant to the Villain — the male lead tortures and kills people on-page as a main character), two for a main character currently having a child before the epilogue (Meet Me at the Lake, Funny Feelings), one for being a sapphic romance (Payback's a Witch — violates the man/woman rule), one attributed to the wrong author entirely on first guess (Meet Cute Club, which turned out to be an m/m romance by different authors, not a Roselle Lim book — caught during verification, before any output existed, so this is a research-stage catch, not a produced-then-corrected error like Run 1's), one for a disqualifying main-character backstory (The Idea of You), and one for a main character sexually coercing a secondary character (Just My Type). None of these 8 reached a draft or final list, so none of it is a case of grading a corrected output — per the rubric's grade-what-was-produced rule, there was nothing here to grade down, since nothing defective was ever produced.

  • Criterion 1 (15 books): pass — 15 entries returned.
  • Criterion 2 (real/attributed): pass — all 15 titles and authors verified via publisher pages, Goodreads, and reviews; all real and correctly attributed. No misattribution reached the delivered list.
  • Criterion 3 (no pregnancy/child): pass — no main character is a parent/guardian or pregnant before the epilogue in any of the 15. This criterion did real work during vetting: it's why Meet Me at the Lake and Funny Feelings were dropped (see above). Given that Run 1's own criterion 3 pass turned out to be wrong on a closer, separate-session look (see run-01.md), this pass should be read as this session's best verification, not as independently confirmed — it hasn't had that same second look yet.
  • Criterion 4 (not in already-read.md): pass — none of the 15 titles or authors appeared in the specific-books or skip-all-authors sections of already-read.md as it stood before this run (per the rubric's since-fixed wording on grading against the pre-run state, not the live file).
  • Criterion 5 (not on skip-all-authors list): pass — cross-checked all 15 authors against the skip-all-authors section; no matches. This list ruled out a large number of otherwise-obvious picks before they became candidates (Ali Hazelwood, Emily Henry, Sarah J. Maas, and others were excluded either by full-author ban or because every title of theirs checked was already in the specific-books list).
  • Criterion 6 (no duplicate author): pass — 15 distinct authors.
  • Criterion 7 (no novellas): pass — all 15 are full-length novels per publisher listings.
  • Criterion 8 (no prohibited main-character types): pass — no criminal/mafia/vampire/demon/alien/serial-killer main characters in the final 15. (Two related but distinct violations were caught and dropped during vetting — see the vetting note above; they involved a main character kidnapping/torturing another character, not a prohibited character type as such.)
  • Criterion 9 (content-warning format/coverage): pass, with 2 unresolved low-confidence items marked unverifiable (2 of 15 entries)
  • Icebreaker (Hannah Grace): multiple sources flag on-page sexual assault as content in this book, but none found specify which character it happens to or whether it involves either main character. No content-warning line was included on the assumption of no confirmation. If it involves a main or secondary character, this entry is missing a sexual-violence warning line and this criterion would fail for that entry.
  • By the Book (Jasmine Guillory): reviewers describe workplace harassment the main character experiences, but sources don't confirm whether it's sexual in nature or general workplace hostility (the one description found says it's "not from the love interest" and reads as non-sexual). No content-warning line was included on that reading.
  • No other entry showed evidence of an uncovered required topic (rape, torture, murder, cheating, BDSM, cancer, MC's dog dying) or a misformatted warning. Two entries — The Fine Print and Two Wrongs Make a Right — do carry a "main character with PTSD or other mental illness" line (past suicidal ideation for the male lead in one, anxiety for a main character in the other), both reasonably well-sourced.
  • Criterion 10 (heat level correctness): unverifiable (2 of 15 entries)
  • The Fine Print (Lauren Asher): sources directly conflict — one rates it 4/5 "explicit open door," another rates it 2/5 with "a few warm scenes." No heat-level line was included (defaulting to open), which is unverified either way.
  • By the Book (Jasmine Guillory): one comparison source calls it lower-heat than the author's other books and "leaning toward closed door," but nothing found states this as directly as it does for the other 14 entries. No heat-level line was included, which is unverified either way.
  • Criterion 11 (every entry has a link): pass — all 15 entries link to a real page for the title (Goodreads for 14; romance.io for Icebreaker, since no Goodreads URL was confirmed for it during this run).
  • Criterion 12 (exclusion process invisible): pass — the delivered list never mentions already-read.md, the skip-authors list, or why any candidate was excluded; the vetting process above is recorded in this grading file, not in the output itself. Same open question as Run 1's: whether a "note: other books that qualify"-style line (not used in this run, since no such notes were added) would cross this line — moot here since none were included.

Overall: 10 pass, 0 fail, 2 unverifiable (of 12 criteria). Unverifiable = criteria 9 and 10. Both need the book text; review-site summaries can't settle them. This run has not yet had the separate- session regrade that found a real, previously missed failure in Run 1 — treat this score with the same caution until it does.

already-read.md has been updated with these 15 titles (both title and author, in the existing format) so they won't be recommended again. This was deliberately held off when the run was first produced, since appending eval output to a real personal reading-exclusion file without asking felt like the wrong default — done now on request.
