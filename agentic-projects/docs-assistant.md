# Case Study: Building and Evaluating Two Claude Code Skills

I built this project to learn to build an eval harness. It was a way to practice testing results “by hand” versus automating the testing with Python and then using a CI test. I also wanted a project that would solve technical writing-related problems.

Problems to solve:

1. Make commit messages into documentation (release notes)
2. Check that a document followed a style guide or other requirements
